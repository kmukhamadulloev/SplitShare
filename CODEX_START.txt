Core rules:
- Rust owns the product.
- Vue is the browser UI.
- system tray is a thin native adapter.
- no Tauri/Electron.
- no cloud backend.
- real filesystem paths never leave the host.
- streaming only for large files.
- path traversal/symlink escape are release blockers.
- frontend and backend ship in one native desktop release.

Implement the active goal completely, run relevant checks, update docs/issues, then report acceptance criteria one by one.
